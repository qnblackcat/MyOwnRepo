1.0.2

  • Initial release: a rewrite of SlideCut for iOS 15+ (replaces SlideCut).
  • Touch the space key, slide to a letter and release to trigger a shortcut: X/C/V cut/copy/paste, A select all, Z/Y undo/redo, H J K L arrows, N/M previous/next word, S select word, Q/P start/end of line, B/E start/end of document, D translate, Delete removes the previous word.
  • Better Vietnamese Telex support: the letter no longer reaches the input method, so shortcuts never add diacritics to the current word.
  • Space+N moves to right after the previous word; Space+V adds a trailing space after pasting.
